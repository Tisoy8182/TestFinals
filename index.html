01 // SSH HARDENING

Disable root SSH login and default password authentication in /etc/ssh/sshd_config.

sudo sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart sshd
02 // FIREWALL RULES (UFW)

Default deny incoming policy with limited explicit standard access rules.

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp comment 'SSH'
sudo ufw allow 443/tcp comment 'HTTPS'
sudo ufw enable
03 // FILE PERMISSIONS & AUDITING

Secure sensitive authentication storage files against unauthorized reads.

sudo chmod 600 /etc/shadow
sudo chmod 644 /etc/passwd
sudo chown root:root /etc/shadow /etc/passwd
04 // AUTOMATED SECURITY UPDATES

Install unattended upgrades to automatically patch CVE vulnerabilities.

sudo apt update && sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure --priority=low unattended-upgrades
